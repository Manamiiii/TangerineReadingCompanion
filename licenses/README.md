# Supplemental upstream license texts

Most dependency licenses and notices are collected from the installed packages by
`scripts/build-licenses.mjs`. This directory only supplies text omitted from an
upstream npm package. Do not replace missing copyright notices with invented ones.

## tr46 0.0.3

The npm package declares MIT but omits the full license text. Its published
`gitHead` is `a8009f9ce80ff5dbe71dd71e203afe4e4c878d28`.

`tr46-0.0.3-MIT.txt` preserves the upstream maintainer's later explicit MIT text:

- [Upstream addition of the license](https://github.com/jsdom/tr46/commit/3a6f29721e7063b9ffd421e461a54beae6170001)
- [Exact source text](https://github.com/jsdom/tr46/blob/3a6f29721e7063b9ffd421e461a54beae6170001/LICENSE.md)
- [Published package metadata](https://registry.npmjs.org/tr46/0.0.3)

The build fallback is restricted to version 0.0.3. A future version must provide
its own license text or receive a fresh provenance review.
