# 阅读伴侣试用说明

## Windows 首版可试用范围

阅读伴侣可以用于一次真实阅读测试：

- 从书架选择内置《飘》，或使用书名、作者、版本信息、章节目录和可选封面创建个人书籍；添加书籍时也可以选择书籍详情截图自动填充表单，书目 OCR 会保留字段行边界，`书名：…`、`作者：…`、`译者：…` 等带冒号字段会优先识别。模型已配置时，个人书籍默认在创建后自动准备隐藏基础名称，无需未读用户逐条审核。
- 设置实际读到的章节；进度、已遇到名称和个人地图位置保存在当前浏览器。
- 使用“从剪贴板粘贴”、`Ctrl+V` 或截图输入当前小段。
- 截图使用设备端 Tesseract.js 执行简体中文和英文 OCR；结果自动合并硬换行并清理中文误空格，只进入当前页面，必须先人工核对。
- 粘贴或 OCR 后自动使用确定性本机扫描精确查找资料包和已遇到名称；陌生名称使用模型识别，也可以选中段落文字快速记录。
- 可选配置 OpenAI Chat Completions 兼容接口、模型名和 API Key，让模型发现当前小段中的新名称、为个人书籍准备隐藏名称词典，并解释当前概念或段落。只有写入“已遇到”的名称需要读者按当前原文确认；基础词典自动保存，答疑结果临时显示，二者都不能生成正式事实。
- 将地点分类为不确定、现实、虚构、有现实原型或位置模糊。现实地点开放精确搜索；没有结果时可以降级为明确标注的相关参考区域。
- 国际地图搜索优先请求中文名称，必要时可显式调用已配置模型结合当前书籍和章节生成最多三个检索词；候选可携带 GeoJSON 点、河流/山脉路径或区域范围。国内天地图需要浏览器端 Key。
- 虚构、原型或位置模糊地点可以由读者选择一个现实参考区域并设置半径；范围只表示推测背景，不是精确定位。
- 书内功能按“阅读输入 / 已遇到 / 地图 / 设置”切换；确认带无剧透背景的名称后增加“背景资料”，集中展示当前章节已经解锁的注释和公开来源；存在正式事实时也在该页按风险门禁展示。地图支持大画布和全屏展示，并显示当前地图实例已经请求的底图与注记瓦片数。
- 个人书籍可以从书架删除；确认删除后会一并清理该书所有场景的阅读状态。
- 设置页可以导出当前书的试用反馈包，并显示应用版本与资料包版本；反馈包附带当前会话最近 30 次关键操作的脱敏成功/失败诊断，但不包含 API Key、当前段落、搜索词、截图、模型内容、错误原文或其他场景数据。

自由剧情问答、自动人物关系、未来章节解释、移动端原生分享和 Windows 全局快捷键不属于当前能力。

## 启动与安装

环境需要 Node.js `>=20.19.0`。在仓库目录运行：

```bash
npm install
npm run dev
```

Windows PowerShell 如果阻止执行 `npm.ps1`，使用：

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的地址即可进入书架。正式 HTTPS 站点可在 Edge 或 Chrome 地址栏或“应用”菜单中安装为 Tangerine Reading Companion 独立窗口；书架也会在浏览器提供安装事件时显示“安装应用”按钮。

## 建议试用流程

1. 打开应用，确认先显示书架。
2. 选择《飘》，确认书架卡片只突出封面、书名和版本，内置标记位于角落且不显示内部准备数量；也可以创建一本只含三章的个人测试书，并使用书籍详情截图检查书名、作者、译者、出版社、ISBN 和出版时间是否正确填入。
3. 设置真实阅读章节。
4. 从微信读书复制一小段，点击“从剪贴板粘贴”；也可选择截图并执行“提取截图文字”。
5. 核对段落文字，查看自动出现的已知名称；陌生名称运行模型识别，或直接选中文字，设置名称类型及地点性质后确认记录。需要脱离当前段落手工补记时进入“已遇到”。
6. 如需测试模型，进入“设置”，按内置教程填写接口、模型名和 API Key，再创建个人书籍并保留“创建后用 AI 准备基础资料”勾选；创建完成后应显示已准备数量，不出现逐条审核步骤。
7. 确认剪贴板和截图入口在当前段落框上方并排展示；选择截图后只显示缩略图，点击才打开大图。桌面端的无剧透答疑与名称记录使用等高、等宽左右任务区。在“无剧透问问当前内容”中输入概念问题，确认回答只解释当前内容且不会保存；再输入明显询问结局的问题，确认请求在本机被拒绝。
8. 对当前段落中模型发现的新名称，按需修正名称、人物/地点/概念/事件类型和地点性质，只记录原文确实出现的项目。地点初始保持“不确定”时仍可改成现实、虚构、原型或模糊区域；记录后候选继续保留并显示当前章已记录，结果不应附带人物关系、剧情或未来事实。保留一组模型结果后在长段落中间继续输入，确认页面不跳到顶部，旧结果显示需要重新识别且不能误记录。
9. 手动记录一个地点。保持“不确定”时不应出现公网搜索；改成“现实地点”后才出现搜索入口。
10. 进入“已遇到”，检查类型分组、紧凑多列卡片、筛选、分页数量、首页/末页和指定页跳转；点击“查看详情”打开独立阅读记忆弹层，保存个人备注，并在切换到另一章后补记一次出现，确认列表不因详情开合而改变高度。地点记录可展开“地点性质怎么选”，核对五种性质的搜索和精度说明。
11. 进入“地图”，对真实河流、山脉或行政区选择候选，检查服务提供几何时是否显示路径或范围；没有几何时显示代表点。精确地点搜索为空时选择“改用参考区域”，确认地图显示的是带半径圆圈和非精确说明。对虚构地点设置宽泛参考区域，并验证“全屏地图”能铺满应用窗口。选择两个具有代表坐标的地点并点击“计算距离”，确认只显示这一对的方向与直线距离；背景正文优先显示，资料来源默认折叠。
12. 返回书架并重新进入，确认进度、名称分类和个人地图位置仍存在。
13. 暂时退回较早章节，确认较后章节记录及其地图位置被隐藏。
14. 进入“设置”核对应用与资料包版本，导出当前书反馈包；打开 JSON 时可以看到当前书版本、章节、已遇到记录、备注、地图确认和脱敏诊断。诊断中只应出现功能名、供应商类型、成功/失败和错误类别，不应出现原文、搜索词、截图、模型内容、错误原文或 Key。

## 隐私与网络边界

- 段落、截图和 OCR 结果不持久化。
- 本机已知名称扫描与 OCR 本身不把内容发送到模型服务。
- 点击模型识别或当前内容答疑时，当前段落、书名和章节标签会发送到用户配置的接口；个人书籍基础准备只发送书目和版本信息；添加书籍时选择详情截图且模型配置完整，OCR 文字会在同一次操作中发送给该接口以整理书目字段。
- 模型名称识别、个人书籍基础准备、当前内容答疑、书目字段整理和地图检索词建议的成功结果使用页面内临时缓存；完全相同的请求不会重复外发，刷新或关闭页面后清空。
- 模型 API Key 只保存在当前 `sessionStorage`；关闭浏览器后失效，不进入 IndexedDB、导出文件或仓库。
- 公网地图只接收用户主动提交的搜索词；虚构、原型和模糊地点不会发送作品名称，设置参考区域时只发送用户另行填写的现实地区名。不确定地点不提供搜索。
- OCR 语言数据随应用发布；Tesseract.js 运行核心首次初始化可能仍需要网络，之后由浏览器缓存复用。

## 反馈重点

- 微信读书复制到工具的操作是否顺手。
- 中文截图 OCR 的速度和误识别是否可接受。
- 模型候选是否严格限制在当前段落，不添加剧透性解释。
- 地点分类能否阻止虚构地点误搜。
- 河流、山脉和区域的路径/范围是否比单点更有帮助。
- PWA 安装、开始菜单启动和本机数据保留是否符合 Windows 使用习惯。
