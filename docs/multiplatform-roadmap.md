# 多端交付与验收清单

## 产品与范围

橘子阅读伴侣是本地优先、尊重阅读进度的多端可安装应用。共享 Vite / React 阅读核心；Web/PWA 保留访问入口与轻量安装能力，Windows、Android、iOS 优先使用 Tauri 2 外壳，不重写阅读业务。不接入账号、后端或跨设备自动同步；安装在不同端不代表数据自动共享，浏览器与原生端通过 JSON 显式迁移。

主流程：继续阅读 → 接收当前内容 → 自动本机识别 → 安全理解 → 确认记录。只接收读者主动复制、选择、截图或分享的内容；不注入、逆向微信读书，不绕过 DRM 或权限。

## 统一输入与平台契约

入口统一生成 `src/platform/readingInput.js` 中的会话值：

- `kind: text`：`text`，最多 50000 字，空文字允许用于清空。
- `kind: image`：内存 `Blob` 和显示名，PNG/JPEG/WebP/BMP，0–20 MB（不含 0）。
- `kind: link`：`url`，最多 4096 字符，仅 HTTP(S)，禁止内嵌账号密码；只接收，不自动抓取链接或将其视为正文/章节证据。
- `source`：`manual / clipboard / file / capture / share / ocr`；外来额外字段不进入规范值。

`src/platform/index.js` 是适配器组合入口。React 组件按能力调用，不根据 OS/user-agent 分支。剪贴板 `clipboard.read()` 与截图 `capture.region()` 返回规范输入；`shareInbox.subscribe(listener)` 接收规范输入并返回取消订阅函数；`fileExport.save({name, blob})` 返回 `requested / saved / cancelled` 状态；`appLifecycle.subscribe(listener)` 提供 `foreground / background / exit`，并支持显式 reload。Web 下载只可确认已发起，不能声称文件已落盘；Web 不支持区域截图和系统分享接收，不使用缓存模拟收件箱。

这些接口不允许持久化原文、图片、OCR、模型内容或剧透授权，不允许输入进入 hash、日志、数据库、备份或后台队列。输入替换、清空、切书、返回书架与退出时应废弃异步旧结果并释放图片 URL。后台切换只暂停交互，不自动发送内容。原生分享尚未接通前，不宣称已支持。iOS 若只能用临时 App Group 文件跨进程交接，必须先提交最短保留期限、消费后删除、失败/崩溃/冷启动清理、不备份、权限范围方案，并获得明确批准。
