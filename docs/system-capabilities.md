# Tangerine Reading Companion · 系统能力

## 定位

本应用是供个人使用的本地优先阅读伴侣。它帮助读者按当前进度理解人物、地点、概念和时代背景，同时避免未经确认的后续信息进入页面。

- 静态 React/PWA，无后端和账号系统。
- 阅读状态与个人书籍保存在浏览器 IndexedDB。
- 正式内置书资料由版本化静态资料包提供。
- 模型与地图服务只在用户明确操作和配置后调用。

## 已实现能力

- 内置书籍和个人书籍书架。
- PWA 在联网时优先更新应用资源和内置书资料，已加载内容可在断网时回退使用；在线地图瓦片仍不承诺离线可用。
- 书目截图 OCR、确定性字段解析与受限模型校对。
- 章节进度、已遇到名称、个人备注和地点确认。
- 文本、剪贴板及截图 OCR 输入。
- 当前资料包精确匹配与模型候选识别。
- Leaflet 地图、现实地点搜索、参考区域和 GeoJSON 展示。
- 三级剧透风险与单次授权。
- 个人书籍隐藏名称词典和当前内容无剧透问答。
- 脱敏试用反馈导出。
- 阅读专用 JSON 备份、恢复和 TangerineTools 备份兼容导入。

应用页眉只保留折叠的“数据管理”入口，备份与恢复不会占用日常阅读主操作区。Windows 安装提示仅在浏览器实际提供安装动作时出现。

## 数据边界

数据库名为 `tangerine-reading-companion`，Dexie schema v1 只包含 `meta: 'key'`。持久化键包括：

- `readerPersonalPackage:{packageId}`：个人书籍资料包。
- `readerState:{editionId}`：按阅读版本隔离的进度与个人已读记忆。旧工具遗留的带场景 key 会在首次读取时按版本懒复制到该规范 key，旧记录保留，不修改 Dexie schema。

备份只包含这两类记录。导入按 key 合并，不删除备份中缺少的本地记录。

## 非目标

- 不托管电子书正文，不提供 DRM 绕过或全文建库。
- 不自动解锁剧情资料，不把模型记忆作为正式来源。
- 不提供云同步、多用户协作或账号系统。
- 不为虚构地点伪造现实坐标。
- 不在没有可验证双阶段门禁时开放无边界自由问答。
